# Crazy AE Cables

**Crazy AE2 Cables** is an addon for **Applied Energistics 2** that adds a line of high-capacity cables, from x8 up to x8192 channels, plus a Creative tier with **Integer.MAX_VALUE** channels capacity (2147483647). Build huge ME networks without drowning in dense-cable spaghetti.

## Dependencies
- [Applied Energistics 2](https://www.curseforge.com/minecraft/mc-mods/applied-energistics-2)
- [Simple Updates Checker](https://www.curseforge.com/minecraft/mc-mods/simple-updates-checker) (client-side)
